启动本机工作台后自动匹配四个原生程序

Windows 工作台启动后会自动搜索 Athena、Artemis、Hephaestus 和 HAMA，并启用下方全部数据处理功能。GitHub 公开页只提供安全入口，不会把实验数据提交到网站。

打开本机工作台 下载 Windows 桌面版（推荐） 下载 Python 便携包 查看数据处理与拟合说明

首次使用：下载并解压桌面版，双击 XAFS-Workbench.exe；以后由它自动打开工作台并匹配四个程序。若“打开本机工作台”显示无法访问，表示桌面版尚未运行。跨电脑使用时请运行 launch_network_workbench.cmd，再打开脚本显示的主机名网址。

网页计算后端连接

本机打开时使用当前页面服务。跨电脑时填写服务机脚本显示的地址，例如 http://LAB-PC:8765；访问密钥只保存在当前浏览器标签会话中。
